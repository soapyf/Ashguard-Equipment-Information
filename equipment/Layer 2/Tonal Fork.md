# [Ash] - Tonal Fork v1.0.0

A left hand anti mine device. 
When activated detonates mines in a full circle around the avatar up to 20m away.

## Specs
| Name                | Value        |
|---------------------|--------------|
| Layer               | L2L          |
| Range               | 20m          |
| Arc                 | 365°         |
| Tick Rate           | 1s           |
| Mana Activation Cost| 25           |
| Mana Cost per Tick  | 7.5          |
| Melee Arc           | 45°          |
| Melee Rate          | 0.33         |
| Melee Range         | 5.00         |




## Commands
All Commands Are On Channel 1. Default keybinds are listed below.

| KeyBind    | Chat Command | Description      |
|------------|--------------|------------------|
| Shift + 2  | d2           | Draw weapon      |
| —          | s2           | Sling weapon     |
| Q          | aux          | Start/Stop       |
| F          | melee        | melee            |
